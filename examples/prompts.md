# Prompt Examples

## 建立学习地图

```text
使用 $learn-by-evidence 帮我系统学习数据库事务。
先把目标拆成可观察的能力阶段，给出常见错误、代表练习和过关标准。
现在不要开课，也不要考我。
```

## 开始一次小步学习

```text
我今天有 30 分钟，继续 Retrieval 学习。
从当前最关键的薄弱点开始，一次只留一个需要我回答的任务。
```

## 诊断概念混淆

```text
我总分不清 recall、precision 和 reranking。
不要先给完整教程，用一个问题判断我具体混在哪里。
```

## 编程陪练

```text
带我学习 JavaScript 闭包。
示例可以讲，但真正的练习先让我自己写；助手生成的代码不要算作我的掌握证据。
```

## 考试复习

```text
根据我提供的 2026 年考纲复习导游业务。
区分知识点覆盖率和我的实际掌握率，旧政策要标版本。
```

## 创作技能

```text
带我练习悬疑小说开篇。
先和我约定 3 个评价维度，让我自己写，再按作品证据反馈；不要把一种审美当唯一答案。
```

## 直接获得答案

```text
今天不做测评，直接解释 Python 装饰器并给一个最小例子。
把它标记为学习材料，不要记成我已经会了。
```

## 保存恢复点

```text
今天先到这里，不要再出题。
请总结本次有证据的能力、尚未验证的部分和下次恢复点。
如果不能真实保存，就给我可复制的 checkpoint。
```
